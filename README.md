# MerdPOSDev

This repository contains multiple MERDPOS development tracks.

## MERDPOS Beta entry point

The active MERDPOS Beta web portal is **not** sourced from the default `main` branch. Its authoritative branch is:

`namecheap-beta-live`

For any MERDPOS Beta task, first resolve the current `namecheap-beta-live` HEAD and read that branch's root `AGENTS.md` plus its `.ai/` bootstrap files before planning or implementing changes.

Do not continue Beta work from a stale feature branch or from repository/chat state inherited before entering the MERDPOS BETA project. Re-bootstrap from the authoritative branch and reconcile branch lineage first.

This file is intentionally only a discovery pointer; Beta architecture, state, decisions, deployment procedure and execution gates live on `namecheap-beta-live`.
